# Swan Ganz Interface

### Introduction

The contributors to this senior design project were Nathan DeLaRosa, Ashton Knecht, Jack Son, and Jerry Xia under the supervision of Dr. Jonathan Valvano.

This project aims to create a custom, low-cost interface for a Swan-Ganz heart catheter, bypassing the need for expensive cardiac output computers. The catheters intended to be interfaced is the *part number needed* produced by Edwards Lifescience. These catheters interface the *part number needed* pressure transducer also made by Edwardss Lifescience.

The project is split into three sections, the interface hardware, MSPM0 firmware, and the desktop application software. Greater detail about each of these sections can be found below on their distinct readme files.
